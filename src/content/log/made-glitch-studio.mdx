I wanted to apply a quick dither effect to some photos for a presentation. I also wanted to test Google's Gemini 3 capabilities after seeing a few people rave about it online.

So I built a quick dither app with one prompt. It did exactly what I wanted it to do. You can download the [index.html file here](https://github.com/thisismattsmith/dither) and run it locally.

Impressed with the speed and accuracy I decided to expand on the idea and add more effects, which Gemini called "glitch studio" and I could not be bothered thinking of a new name.

Here it is: [glitch studio](https://glitch-studio.nelify.app/). 

You can add a dither effect but I also added a few more like pixelation, outlines, monochrome and CRT scans. You can stack effects on top of each other to come up with new styles.
