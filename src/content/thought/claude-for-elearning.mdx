If you’re using Claude to create eLearning don’t create something that looks like a course made in Articulate Rise. This is your opportunity to imagine how things could be different. 

You’re starting with a blank page, not a block template.

You're not limited by limited feature sets and (in the case of Articulcate products) buggy features and workarounds. You can start exactly where you should, with these questions:

1. What will be the best way to represent authentic practice that matches the performance context? 
2. How can this be as engaging as possible? (while not straying from point #1)
3. How can this be as user friendly as possible?
4. How can I make the most accessible experience possible?
5. How can I make this short as possible, while still being effecftive, so I people can finish it can get back to work?
